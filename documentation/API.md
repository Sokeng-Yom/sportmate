# SportMate API cheat sheet

Generated by `python -m app.db.export_api_docs`. Do not edit by hand.

Every endpoint needs `Authorization: Bearer <supabase access token>`. Errors are `{"detail": "message"}` with status 400, 401, 403, 404, 409, 422 or 429. Live chat delivery uses Supabase Realtime, not this API.
